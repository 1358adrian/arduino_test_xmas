  - Press the button to close immediately and enter into closed state. Then toggle between opening and closing the door.

If the mode is manual when the object from the ultrasonic sensor is getting near, and detected in less than 20cm, whether the door is manually opened or closed:
- Exit manual mode, open the door immediately (if closed, or keep it open) in auto mode.

If false triggers occured by the following conditions:
- Rapid button press (less than 100ms)
- Inconsistent ultrasonic sensor input (reading in less than 20cm switches abruptly and shortly to a reading more than 20cm in less than 100ms, then back to a reading in less than 20cm, or reading in more than 20cm switches abruptly and shortly to a reading less than 20cm in less than 100ms, then back to a reading in more than 20cm)

Then alert it through short beep (660Hz, WARNING_FREQ_3) and serial monitor. False triggers must be occured thrice.
If false triggers occured thrice, alert it through continuous beep (880Hz, WARNING_FREQ_4) and serial monitor, telling the user that the system ignores all inputs for 10 seconds, simulating lockout before it goes back to normal operation.

===
Provide an ESP32 code to design and implement an enhanced smart door system using an ESP32 that integrates timers, interrupts, and a proximity sensor to simulate an intelligent door that can respond automatically or manually through button control.
 
Instructions
Inputs:
Push Button (Manual Control):
Used to manually open or close the door (with interrupt).
Ultrasonic Sensor (HC-SR04):
Detects proximity to trigger automatic door opening.
Timer (Hardware Timer):
Automatically closes the door after a preset delay.

Outputs:
Servo Motor: Simulates the door lock or opening mechanism.
Green LED: Door open indicator.
Red LED: Door closed indicator.
Buzzer: Signals door operation and alerts during lockout.
 
Programming Tasks:
Initialize I/O Devices
Configure the ultrasonic sensor pins (TRIG, ECHO), servo, LEDs, buzzer, and button with internal pull-up.
Set up a hardware timer to handle automatic door closure after 5 seconds.
Manual Mode (Interrupt-Driven):
Use an external interrupt for the push button.
On press, toggle between opening and closing the door.
Automatic Mode (Sensor-Driven):
Continuously measure distance using the ultrasonic sensor.
If an object or person is detected within 20 cm, open the door automatically.
Keep it open for 5 seconds, then close it using the timer interrupt.

Error and Lockout Handling:
If three false triggers (e.g., button pressed rapidly or inconsistent sensor input) occur, the system should:
Activate the buzzer continuously.
Ignore all inputs for 10 seconds (simulate lockout).
Use timer-based delay or millis() for lockout instead of blocking delay().

System Feedback:
Display events in the Serial Monitor:
Door opened (auto/manual)
Door closed
Lockout activated / cleared
Sensor distance readings

Bonus Challenge:
Add a door obstruction detector: If the ultrasonic sensor still detects an obstacle when attempting to close, keep the door open and issue a buzzer warning until the obstacle clears.
